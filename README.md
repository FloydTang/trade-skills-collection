# 外贸Skill源仓库

> 层级方向标记：这是 `外贸Skill` 的源仓库层，只做开发、验证、内部维护和同步来源；不是课程工作间默认读取入口，也不是作战台展示层。

这个仓库当前公开可交付的是主动开发主线，不是泛 Skill 合集：

- `主动开发链路组合包`
- `客户搜索skill`
- `线索整理skill`
- `客户背调skill`
- `开发信skill`

如果你来自线上课：

- 课程里已经讲过全景图、数据资产框架和增强执行逻辑
- 仓库这里不重复讲课
- 仓库只保留最小使用入口、边界和脚本

## 统一口径

- Skill 是标准化能力，负责搜索、线索整理、客户背调、开发信等可复用动作，不是固定表格模板。
- 企业表格是企业个性化资产：用户已有表头优先沿用；没有可用表格时，再由龙虾按企业产品、市场和流程新建够用表。
- 标准 Base、课堂 Feishu Sandbox 和示例字段只作为参考映射，不是企业落地前置条件。
- 客户搜索支持公开搜索和用户授权数据源接入；企业自己的数据源越好，同样工具跑出的线索越快、越准。
- 客户背调是当前链路的核心判断层，负责近期客户信号、市场/合规信号、风险判断和销售角度；开发信只调用这些信号生成复核草稿。
- 当用户确认新字段、客户分级、搜索数据源、近期信号判断、市场信号来源、背调规则、开发信风格、禁用表达或行业习惯时，龙虾必须追问：`是否更新到对应 Skill 以便下次自动复用`。真实写入必须得到用户授权。

执行契约见：

- `企业表格适配与Skill沉淀规则.md`

## 当前推荐安装范围

当前只建议优先使用这 5 项：

- `主动开发链路组合包`
- `客户搜索skill`
- `线索整理skill`
- `客户背调skill`
- `开发信skill`

根目录里看到的其他目录，当前主要用于内部工作间；未发布方向已收进 `工作间/孵化中/`，都不属于默认安装范围。

## 本地分工

| 层级 | 路径 | 负责什么 | 不负责什么 |
| --- | --- | --- | --- |
| 源仓库层 | `工具工作间/01_在整理的Skill/外贸skill源文件` | 开发、验证、脚本、源 README、同步来源 | 不给课程工作间默认读取，不直接给作战台展示 |
| 展现层 | `工具工作间/02_场景拆解/外贸业务主干Skill` | 制作中、候选、内部维护、课程化前的说明镜像 | 不作为成品库 |
| 成品层 | `半斤九两工具库/外贸业务主干Skill` | 已提纯、已验证、可追溯的外贸Skill资产 | 不放过程噪音 |
| 课程层 | `半斤九两课程库` | 用户可见课程内容和作战台同步内容 | 不直接承接源仓库过程稿 |

已经达到可演示或可交付的 Skill，应先落到 `半斤九两工具库/外贸业务主干Skill`，再交给课程工作间课程化。作战台不直接读取工具工作间或工具库原始目录；作战台同步的是课程库和课程化同步稿。

## Quick Start

先跑最小闭环：

```bash
python3 ./主动开发链路组合包/scripts/run_minimal_demo.py
```

先看关键输出：

- `主动开发链路组合包/outputs/demo-run/09-container-bundle.json`
- `主动开发链路组合包/outputs/demo-run/10-container-bundle.md`
- `主动开发链路组合包/outputs/demo-run/11-lead-workflow.csv`
- `主动开发链路组合包/outputs/demo-run/12-feishu-sandbox-bundle.json`

如需自检：

```bash
python3 ./主动开发链路组合包/scripts/run_regression_checks.py
```

## 固定边界

当前最稳的定位是：

- 公司级可用
- 人名职位级基本可用
- 精准邮箱级仍不足

固定提醒：

- 没有真实公开来源，不应强行推进下一步
- 私有、付费或企业内部数据源必须由用户提供或授权
- 开发信节点不自行编造“客户最近发生了什么”
- “skill 已安装” 不等于 “能力已可用”
- 工具依赖要区分已安装、已配置、已登录、已跑通
- LinkedIn 类能力不是默认开箱即用
- 云端和本地环境可能存在差异

## 当前主语义

当前主线不再把“飞书搭建成功”当作课堂成就感前置条件。

当前仓库默认表达为：

- 主线是标准数据契约 + 可复核主动开发闭环
- 飞书是课堂标准沙盘，不是企业唯一容器
- 公开容器默认支持 `JSON / Markdown / CSV`
- Feishu 作为容器适配器保留
- CRM / ERP / 邮箱草稿箱当前只留扩展位

统一契约文档见：

- `标准数据契约.md`
- `企业表格适配与Skill沉淀规则.md`

## OpenClaw 默认理解

- 默认主入口：`主动开发链路组合包`
- 4 个单节点是阶段能力，不是 4 个平级主入口
- 仓库负责开源说明
- 增强事项直接看飞书入口，不在仓库里继续展开
