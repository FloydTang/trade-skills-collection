## 作战台需要同步更新的内容

作战台当前只需要做“成品索引同步”，不要把孵化中节点塞进主页面。

建议同步：

1. 作战台成品 Skill 入口读取 `半斤九两工具库/外贸skill`。
2. 主动开发作战包说明使用“1 个组合包 + 4 个阶段 Skill”。
3. 弹药库或后续扩展区可以预留三个验证中节点：
   - Mail Group / 客群分组开发信
   - 社媒账号初步调研
   - 外贸资料路由与飞书知识库承接
4. 对验证中节点统一加状态：
   - `验证中`
   - `未进入公开默认安装`
   - `不自动发信 / 不确认官方账号 / 不绕过飞书权限`

## 推荐推进顺序

1. 先跑 `trade-mail-group` 最小样例，争取第一个从“可演示前验证中”推进到“可演示”。
2. 再跑 `trade-social-account-scan` 公开网页样例，先建立保守输出，不急着接 Sherlock / Maigret。
3. `trade-feishu-kb` 只做内部资料路由和授权回读验证，不作为用户侧业务 Skill 宣传。
4. 同步更新课程正文，尤其是 `飞书增强执行词-复制入口.md` 和 Lesson 04-08。
5. 最后再做作战台同步索引，避免本地课程和 Skill 口径没收口就上线。

- 不把飞书 KB 写成飞书 Base 表格 Skill。
