# 作战台与课程中心 Skill 同步方向

更新日期：2026-05-20

## 一句话结论

作战台不直接读取工具工作间或工具库原始目录。

当前正确流程是：

```text
工具工作间
-> 半斤九两工具库
-> 课程工作间
-> 半斤九两课程库
-> 作战台同步
-> 飞书知识库同步
```

工具库里的两份入口文档，先提供给课程工作间读取和学习；课程工作间把 Skill 资产改写成课程章节、作业、用户动作、权益边界和作战台同步稿后，再进入课程库、作战台和飞书知识库。

1. `外贸业务主干Skill云端同步清单.md`：外贸业务主干 Skill，包括组合包、单点 Skill、验证中业务节点、市场雷达和飞书承接。
2. `精选外挂开源Skill云端同步清单.md`：精选外挂开源 Skill / 工具，包括设计、内容、知识库、监控、验证和研发辅助。

内部仍可以保留立项、验证台账和路线图，但这些不是云端默认读取入口。

当前不要把 `trade-mail-group`、`trade-social-account-scan`、`trade-feishu-kb`、`trade-market-pulse` 放进公开默认安装清单，也不要放进作战台主页面第一层。

## 作战台需要同步更新的内容

作战台当前只需要接收“课程化后的成品索引同步”，不要把工具库原始目录或孵化中节点塞进主页面。

建议同步：

1. 课程工作间读取 `半斤九两工具库/外贸skill`，输出课程化同步稿。
2. 作战台读取课程库、课程化同步稿、授权学习链接和飞书知识库索引。
3. 主动开发作战包说明使用“1 个组合包 + 4 个阶段 Skill”。
4. 弹药库或后续扩展区可以预留四个候选节点：
   - Mail Group / 客群分组开发信
   - 社媒账号初步调研
   - 外贸资料路由与飞书知识库承接
   - 外贸市场脉搏 / 每日情报监控
5. 对验证 / 设计中节点统一加状态：
   - `验证中` 或 `设计中`
   - `未进入公开默认安装`
   - `不自动发信 / 不确认官方账号 / 不绕过飞书权限 / 不把热点信号当确定结论`

## 推荐推进顺序

1. 先跑 `trade-mail-group` 最小样例，争取第一个从“可演示前验证中”推进到“可演示”。
2. 再跑 `trade-social-account-scan` 公开网页样例，先建立保守输出，不急着接 Sherlock / Maigret。
3. `trade-feishu-kb` 只做内部资料路由和授权回读验证，不作为用户侧业务 Skill 宣传。
4. `trade-market-pulse` 作为下一组自动化情报候选，先验证家纺 / 家居出口样例，再决定是否接自动化调度。
5. 同步更新课程正文，尤其是 `飞书增强执行词-复制入口.md` 和 Lesson 04-09。
6. 最后再做作战台同步索引和飞书知识库同步，避免本地课程和 Skill 口径没收口就上线。

## 当前不要做什么

- 不把验证中 Skill 写成已可交付。
- 不把飞书 KB 写成飞书 Base 表格 Skill。
- 不把 Mail Group 接成自动发信系统。
- 不把 Sherlock / Maigret 当官方账号确认工具。
- 不把公开仓库写成增强权益正文。
- 不把作战台首页改成完整知识库或课程站。
- 不把社媒热度、论坛讨论或海关数据线索直接写成确定市场结论。
