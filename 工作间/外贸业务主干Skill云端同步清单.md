## 这份文档解决什么

这份文档只回答一个问题：

哪些外贸业务主干 Skill 已经可以提供给课程工作间读取、课程库改写、作战台同步和飞书知识库同步。

这里收录的是半斤九两围绕外贸业务动作定制、验证或正在孵化的 Skill。外挂开源工具、设计工具、内容工具和通用 Agent 方法不放在这里，统一看：

- `../精选外挂开源Skill/精选外挂开源Skill云端同步清单.md`

内容营销 / TikTok 陪跑是外贸业务主干里的新业务分支，不再单独作为第三入口。

## 课程工作间读取规则

课程工作间读取工具资产时按三层读：

1. **成品层**：已经落到半斤九两工具库，可作为课程化默认素材源。
2. **制作中 / 孵化层**：仍在工具工作间验证，只能作为课程候选、弹药库候选或后续路线。
3. **内部维护层**：只服务立项、验证、课程同步和历史追溯，不给作战台或课程库正文默认读取。

硬边界：

- 成功成品必须落到 `半斤九两工具库/外贸业务主干Skill`。
- 制作中、孵化中、验证中内容留在 `工具工作间`。
- 作战台不要直接读取工具工作间或工具库原始目录；用户可见内容应先经过课程工作间整理。
- 课程库和飞书知识库同步时，必须保留来源、状态、验证证据和权限边界。
- 验证中 / 设计中 Skill 必须显式标注状态，不能写成已可交付。
- 单点 Skill 使用各自独立仓库链接；组合包只用于完整闭环。

## 流转规则

```text
候选
-> 立项
-> 最小样例验证
-> 可演示
-> 落库到半斤九两工具库
-> 课程工作间课程化
-> 进入半斤九两课程库
-> 同步作战台和飞书知识库
```

每次从工具工作间进入工具库，必须满足：

- 有 `README.md`
- 有 `SKILL.md`
- 有最小样例输入
- 有明确输入、输出、边界和默认行为
- 已跑通最小样例
- 已写清是否可独立运行、是否被组合包调用
- 已标注公开仓库或本地落点

进入工具库后，工具工作间只保留：

- 立项记录
- 验证记录
- 后续优化路线
- 必要的追溯链接

不要再在工具工作间保留一份对外可用成品说明当默认入口。

## 内容营销 / TikTok 陪跑分支

来源页是“AI+内容营销 主题龙虾课 / 龙虾视频营销操作手册”。它的主链路可参考：竞品调研、客户画像、视频选题库、脚本与拍摄任务、AI 视频制作、社媒发布复盘、独立站询盘承接。

当前判断：

- 有价值，但更像工具项目手册，不是可以直接发给学员的正式课程。
- 只采用链路和字段思路，不照搬“省掉 80%”“被动获客”这类承诺式表达。
- 先做三个小方向：账号与内容信号调研、B2B 视频选题库、脚本任务包。
- 暂不做 TikTok 自动发布、自动投流、普通用户代码视频渲染，也不做一个大而全 TikTok 总包。
