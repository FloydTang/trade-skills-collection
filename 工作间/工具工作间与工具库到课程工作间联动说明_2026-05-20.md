# 工具工作间与工具库到课程工作间联动说明 2026-05-20

> 方向标记：本文件是工具工作间、工具库、课程工作间、课程库、作战台、飞书知识库和 HomeMac 服务库之间的当前联动 SOP。

## 一句话

工具工作间和工具库不是作战台的直接展示源。

工具工作间负责孵化和验证，工具库负责保存已提纯、已验证、可追溯的 Skill 资产。真正给用户展示的内容，应先进入课程工作间完成课程化表达，再沉淀到课程库，同时同步作战台和飞书知识库。

## 正确链路

```text
工具工作间
-> 半斤九两工具库
-> 课程工作间
-> 半斤九两课程库
-> 飞书知识库同步 + 作战台同步
-> HomeMac 服务库自动镜像
-> 论坛推广、答疑和反馈回流
```

反馈回流只回到工具工作间评估，不自动改写工具库、课程库或作战台。

## 各层职责

| 层级 | 负责什么 | 不负责什么 |
| --- | --- | --- |
| 工具工作间 | 候选、立项、POC、验证台账、失败边界、后续优化 | 不作为用户可见入口，不给作战台直接抓取 |
| 半斤九两工具库 | 已验证或准成品 Skill、仓库链接、安装入口、最小样例、风险边界 | 不负责课程讲法，不直接决定作战台页面展示 |
| 课程工作间 | 把工具资产翻译成课程章节、作业、案例、用户动作和权益边界 | 不把未验证工具写进课程，不绕过工具库审核 |
| 半斤九两课程库 | 保存用户可学习、可交付、可追溯的课程正文和作业体系 | 不保存 POC 噪音或未验证技术候选 |
| 作战台 | 读取课程化后的作战包、弹药卡、学习链接和用户可执行动作 | 不直接展示工具工作间过程文档 |
| 飞书知识库 | 保存会员增强内容、复制入口、长期资料和权限内同步页 | 不替代公开工具库，也不把增强正文写回开源仓库 |
| HomeMac 服务库 | 自动镜像已完成课程库、飞书和作战台同步口径确认的稳定资料，给 Mars/Hermes 等 HomeMac 智能体读取 | 不作为编辑层，不提前读取课程工作间或工具工作间草稿 |
| 论坛 | 推广、答疑、案例讨论、收集反馈 | 不作为工具库上游，不自动发布到作战台 |

## 交给课程工作间时必须带上的字段

每个准备进入课程工作间的 Skill 或工具资产，至少要讲清：

| 字段 | 要求 |
| --- | --- |
| `skill_id` | 稳定英文 id 或仓库名 |
| `显示名称` | 课程和作战台可读的中文名称 |
| `当前状态` | 可交付、可演示、验证中、设计中、仅参考 |
| `工具库落点` | 本地路径或仓库入口 |
| `公开来源` | GitHub、官方文档、本地 Skill 或课程源 |
| `适用场景` | 主动开发、内容营销、跨境电商、竞品监控、知识库等 |
| `用户动作` | 用户在课程里应该怎么用，而不是工具内部怎么实现 |
| `验证证据` | 最小样例、回读结果、失败边界或误判说明 |
| `安全边界` | 隐私、账号、API Key、数据出境、自动发送、误判风险 |
| `课程同步建议` | 应更新哪一课、哪一段、哪一个作业或案例 |
| `飞书同步建议` | 是否需要进入飞书增强入口、知识库索引或复制词 |
| `作战台呈现建议` | 主页面、弹药库、学习链接、论坛帖，或暂不展示 |

## 作战台同步原则

作战台同步的是课程化后的内容，不是工具库原始目录。

作战台可以引用工具库里的仓库链接、安装入口和 Skill 元数据，但用户看到的主表达应来自课程库或课程工作间整理后的同步稿：

- 这是什么业务动作
- 什么时候用
- 用户需要准备什么
- AI 会输出什么
- 哪些必须人工复核
- 它属于哪个课程章节或权益层

## 飞书知识库同步原则

飞书知识库和作战台应该同批次同步，但职责不同：

- 作战台负责作战包、弹药卡、学习入口和用户动作。
- 飞书知识库负责增强复制词、长期资料、课程补充、会员权益和权限内沉淀。
- 工具库里的公开仓库说明不直接搬成飞书增强正文。
- 飞书增强正文也不写回公开工具库。

## HomeMac 服务库同步原则

HomeMac 服务库排在飞书知识库和作战台同步之后。

它不是新的课程编辑层，而是自动镜像层：本机确认课程库稳定、飞书知识库和作战台同步口径无误后，再由同步脚本把课程库、工具库和规则文件镜像到 HomeMac 服务库，供 Mars、Hermes 和其他 HomeMac 侧智能体读取。

Mars 读取服务库时只应做论坛日更、旧帖补充、提问和反馈收集，不直接改课程库或工具库。

## 禁止项

- 不让作战台直接读取工具工作间。
- 不让作战台把工具库当最终用户展示层。
- 不让论坛内容自动进入工具库。
- 不让验证中 Skill 进入课程库正文成为确定结论。
- 不让飞书增强权益正文回写到公开仓库或公开工具库。
- 不让课程工作间绕过工具库，直接采用未验证候选。
- 不让 Mars 把 HomeMac 服务库理解成课程编辑源。

## 当前结论

工具库是课程工作间的上游素材库，不是作战台的最终展示库。

作战台最终应读取课程库、课程化同步稿、授权学习链接和飞书知识库索引。工具库只提供可追溯的 Skill 资产、仓库链接、验证证据和边界说明。HomeMac 服务库只服务后续智能体读取和论坛更新，不前置参与课程发布判断。
