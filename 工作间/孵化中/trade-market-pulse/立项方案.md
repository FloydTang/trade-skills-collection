# trade-market-pulse 立项方案

## 基本信息

- Skill 名称：外贸市场脉搏 / 每日情报监控 Skill
- 建议英文名：`trade-market-pulse`
- 所属业务节点：市场研究 / 竞品监控 / 行业热点 / 自动化情报
- 负责人：Codex + Floyd
- 当前状态：设计中

## 业务问题

- 这个 Skill 要解决的具体问题是什么：
  外贸业务需要持续关注目标市场、竞品、渠道、平台、政策、社媒和客户侧变化，但人工每天刷新闻、官网、电商、社媒和论坛成本很高，也容易把热点噪音当成重要信号。
- 当前人工是怎么做的：
  人工临时搜索 Google、看 LinkedIn / TikTok / YouTube、翻竞品官网和电商店铺，再凭经验判断哪些值得跟进。
- 为什么值得被做成 Skill：
  半斤九两工作台里已有 `AI热点 / 每日内容同步` 的来源分层、筛选规则、速递和待处理面板机制；这套机制迁移到外贸后，可以把每日市场观察变成可配置、可复核、可课程化的业务节点。

## 成功标准

- 最小成功结果是什么：
  输入行业、产品、目标市场、目标客户画像和重点来源后，输出一份当日 / 本周期外贸市场信号速递，包含来源、证据等级、业务影响、建议动作和待补证据。
- 用户拿到结果后，能直接做什么下一步动作：
  人工决定哪些信号进入客户背调、开发信角度、选品 / 报价讨论、竞品 watch、内容选题或继续观察。
- 什么情况下算“做出来了但还不能交付”：
  能生成热点摘要，但无法解释来源可信度、无法回到原始出处，或把社交讨论直接写成确定市场结论。

## 输入

- 最小输入：
  行业、产品范围、目标市场、目标客户画像、关注周期、输出语言。
- 推荐输入：
  竞品名称 / 官网、电商平台、重点关键词、禁用来源、优先来源、可用数据源、业务目标。
- 输入不完整时的默认行为：
  可以先按行业和产品做宽泛观察，但必须降低精准度，并输出“建议补充字段”。
- 输入示例：
  见 `examples/minimal-input.json`。

## 输出

- 核心输出：
  外贸市场脉搏速递、建议人工晋升 / 继续观察 / 忽略列表、每条信号的证据等级、业务影响和下一步动作。
- 输出格式：
  Markdown / JSON
- 建议字段：
  `id`、`title`、`source_ref`、`published_at`、`source_bucket`、`discovery_source`、`evidence_level`、`is_primary_source`、`freshness_days`、`summary`、`detail_brief`、`why_it_matters`、`trade_relevance`、`target_customer_relevance`、`impact_area`、`status`、`next_action`、`raw_payload`。
- 输出示例：
  等最小样例跑通后补入 `examples/`。

## 核心规则与边界

- 必须遵守的业务规则：
  每条信号必须有来源；聚合来源必须尽量回原文；社交来源默认只能做信号，不能做唯一事实；结论必须区分事实、推断和建议动作。
- 哪些信息只能写成推断：
  市场需求变化、客户采购意图、竞品策略动机、价格调整原因、渠道热度持续性。
- 哪些情况必须提示人工复核：
  只有社媒热度、只有二手摘要、来源超过时效窗口、数据样本太少、海关数据无法对应具体买家意图、竞品页面变化缺少上下文。
- 明确不做什么：
  不自动发帖；不自动发信；不绕过平台权限；不做大规模爬取；不提供法律、关税或投资决策结论；不把海关数据当成确定销售机会。

## 依赖与实现方式

- 需要的脚本 / 工具 / API：
  首版先做规则与输出契约；后续可按来源接入网页搜索、RSS、changedetection.io、电商页面监控、社媒公开搜索、授权数据源或人工补采。
- 是否需要联网：
  最小结构样例不强依赖联网；真实样例需要联网或使用已保存的公开来源快照。
- 是面向 Codex、本地脚本，还是 OpenClaw / 龙虾优先：
  首版优先面向 Codex / OpenClaw 可读执行词和本地样例；自动化阶段再考虑定时任务。
- 是否需要 `for-openclaw/` 变体：
  等最小样例和输出契约稳定后再判断。

## 课程与内容映射

- 对应课程：
  外贸主动开发课的市场观察、竞品监控、客户背调前置情报、30 天落地路径；也可承接半斤九两工作台里的 AI 热点每日同步机制。
- 可讲成什么案例：
  如何把每天刷新闻、看竞品、看平台和看社媒，变成有来源、有筛选、有下一步动作的外贸市场脉搏。
- 可衍生什么内容选题：
  外贸老板每天该看什么市场信号、竞品监控和市场热点有什么区别、社媒热度为什么不能直接当事实、行业越说清楚 AI 越好用。

## 验收方式

- 最小测试输入是什么：
  一个行业、一个产品范围、两个目标市场、两个竞品、若干关键词和一段目标客户画像。
- 预期输出应包含哪些关键信息：
  速递条目、来源链接、来源桶、证据等级、一手证据标记、业务影响、目标客户相关性、建议动作、待补证据。
- 如何判断这个 Skill 已达到可演示：
  至少 1 组课程样例能稳定输出结构化市场脉搏速递，并能解释每条信号为什么被保留或忽略。
- 如何判断这个 Skill 已达到可交付：
  至少 2 组真实公开行业样例通过；补齐 `SKILL.md`、输出样例、风险边界、自动化频率和失败处理说明。
