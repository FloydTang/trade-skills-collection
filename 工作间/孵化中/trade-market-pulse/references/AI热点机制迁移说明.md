# AI热点机制迁移说明

`trade-market-pulse` 借鉴半斤九两工作台里 `AI热点 / 每日内容同步` 的四个稳定部件：

1. 来源分层
2. 筛选规则
3. 原始速递
4. 待处理面板

## 可直接迁移的部分

- 来源要分桶，而不是混成一堆链接。
- 聚合来源只能做发现器，命中后优先回原文。
- 社交信号默认不能当唯一证据。
- 输出不自动进入主列表，只给人工动作建议。
- 原始速递是真相层，待处理面板是人工速览层。

## 需要改成外贸语义的部分

| AI热点语义 | 外贸市场脉搏语义 |
| --- | --- |
| 九两相关性 | 外贸业务相关性 / 目标客户相关性 |
| AI 产品官方博客 | 政府贸易政策、行业协会、竞品官网、平台官方报告 |
| AI 聚合发现源 | Google News、行业媒体、B2B 平台、电商分类、资源站、论坛索引 |
| X 关键账号池 | LinkedIn、TikTok、X、YouTube、论坛和创作者信号 |
| 人工晋升到内容主列表 | 人工晋升到客户背调、开发信角度、竞品 watch、选品讨论或课程案例 |

## 首版输出动作

- `建议人工晋升`
- `继续观察`
- `忽略`

## 首版保留维度

- 新鲜度
- 信号强度
- 外贸业务相关性
- 目标客户相关性
- 观察价值

## 重要边界

- 外贸场景里“热”不等于“有采购意图”。
- 海关数据有价值，但通常只能证明贸易痕迹，不直接证明当下需求。
- 论坛和社媒可以提供早期信号，但必须降级处理，除非能回到官方发布或一手来源。
- 竞品页面变化如果没有上下文，只能作为待复核信号，不直接解释竞品战略。
