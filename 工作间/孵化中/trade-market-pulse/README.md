# trade-market-pulse / 外贸市场脉搏每日情报 Skill

当前状态：设计中

这个目录用于把半斤九两工作台里的 `AI热点 / 每日内容同步` 机制迁移到外贸场景，形成一个面向行业、市场、竞品、渠道和社媒信号的每日情报 Skill。

## 定位

面向需要持续观察外贸市场变化的老板、业务员、运营和课程学员。

用户只需要说明行业、产品、目标市场、目标客户画像和重点关注对象，Skill 就能围绕这些信息筛选每日值得看的市场信号。输入越清晰，输出越精准；输入较模糊时也可以运行，但必须降低置信度并提示需要补充哪些画像信息。

它不是泛新闻日报，不是舆情平台，不自动替用户做商业决策，也不把社交媒体热度直接写成事实结论。

## 和现有 Skill 的关系

- `竞品监控skill`：负责少量明确 URL 的网页变化监控，例如价格、首页促销、新品集合页。
- `trade-social-account-scan`：负责某个公司公开社媒账号的初步发现和身份不确定性标注。
- `trade-market-pulse`：负责跨来源发现、筛选、证据分级、每日速递和人工动作建议。

换句话说，竞品页面变化、社媒账号动态、电商店铺变化、行业新闻和海关数据线索，都可以成为 `trade-market-pulse` 的来源桶；但它们进入最终输出前必须经过证据分级和人工复核口径。

## 来源分层

首版沿用 AI 热点自动化的三层思想，但改成外贸业务语义：

- `official_primary`：官方一手来源，如政府贸易政策、海关 / 关税公开数据、行业协会、品牌官网、竞品官网、平台官方报告。
- `aggregator_discovery`：发现器，如 Google News、行业媒体、B2B 平台搜索、电商分类页、资源站和论坛索引。
- `social_signal`：社交信号，如 LinkedIn、TikTok、X / Twitter、YouTube、Reddit / 论坛讨论、创作者和渠道账号。

默认规则：

- 官方一手来源可以作为高置信证据。
- 聚合来源必须优先回到原文或官方来源。
- 社交信号默认不能作为唯一证据，除非该账号本身就是一手发布主体。
- 海关数据只能作为贸易痕迹或趋势线索，不直接等同于采购意图。
