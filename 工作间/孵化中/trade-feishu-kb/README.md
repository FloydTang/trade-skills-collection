# trade-feishu-kb / 外贸资料路由与飞书知识库承接 Skill

当前状态：可演示前验证中，内部增强优先。

这个目录用于把工具库、课程工作间、课程库、作战台、飞书知识库和开源 Skill 之间的索引关系整理成可复用流程。

先说人话：它不是给学员直接拿去“搜客户、写开发信”的业务 Skill，而是给内部和龙虾用的资料路由 Skill。它回答三个问题：

1. 这份资料的源头是哪一份？
2. 哪些内容可以放工具库，哪些需要课程工作间转译后进入课程库 / 作战台，哪些只能放飞书增强入口？
3. 同步完以后怎么回读，确认没有放错、漏放、越权放？

## 名称说明

`KB` 是 Knowledge Base 的缩写。这里具体指飞书知识库 / wiki 的索引和同步承接，不是飞书 Base 表格，也不是公开仓库里的独立知识库系统。

## 核心价值

核心价值不是“做一个知识库”，而是防止资料在四层之间错位：

- 工具库：已验证或准成品 Skill、公开仓库入口、验证证据和边界说明
- 课程工作间：把工具资产转成课程章节、作业、案例和作战台同步稿
- 课程正文：完整解释和课程源头
- 飞书知识库：会员增强内容、长期资料、复制入口
- 作战台：筛选后可立即执行的作战包和弹药卡片
- 开源 Skill：公开可安装、可运行、可复用的最小成品

这个 Skill 的输出应该是一张索引和同步建议，告诉协作者：工具库放什么，课程库怎么讲，增强放哪里，作战台同步哪份课程化结果，龙虾能学哪里，哪些步骤必须回读验证。

## 增强入口是什么

这里的“增强入口”指飞书里只给授权用户看的资料入口，例如：

- 增强执行词复制入口
- 年度会员课程正文和补充说明
- 论坛精选 Skill 和月度弹药
- 需要飞书身份或群权限才能看的长期知识库内容

公开仓库可以写“去飞书增强入口看”，但不把这些增强正文复制进公开仓库。

## 定位

面向内部课程维护、年度会员增强权益和作战台内容同步人员。它不是公开默认安装项，也不把增强权益正文放进开源仓库。

## 当前落地边界

- 仓库真实源：当前目录

- 飞书：只处理授权范围内的知识库入口、索引和回读验收
