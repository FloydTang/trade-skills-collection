# trade-feishu-kb / 飞书知识库承接 Skill

当前状态：可演示前验证中，内部增强优先。

这个目录用于把课程库、作战台、飞书知识库和开源 Skill 之间的索引关系整理成可复用流程。

## 名称说明

`KB` 是 Knowledge Base 的缩写。这里具体指飞书知识库 / wiki 的索引和同步承接，不是飞书 Base 表格，也不是公开仓库里的独立知识库系统。

## 定位

面向内部课程维护、年度会员增强权益和作战台内容同步人员。它不是公开默认安装项，也不把增强权益正文放进开源仓库。

## 当前落地边界

- 仓库真实源：当前目录
- Obsidian 展现层：`工具工作间/02_场景拆解/外贸skill/孵化中/trade-feishu-kb`
- 最终工具库：暂不进入公开默认安装清单
- 飞书：只处理授权范围内的知识库入口、索引和回读验收
