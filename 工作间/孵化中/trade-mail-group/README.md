# trade-mail-group / 客群分组开发信 Skill

当前状态：设计中

这个目录用于把作战台里的 `Mail Group 专用执行词` 升级成可验证的单节点 Skill。

## 定位

面向已经有一批客户名单、但还没有分组触达策略的主动开发场景。

它不负责发信，不配置 SMTP，不承诺回复率。它只负责把客户名单整理成可人工复核的分组、触达角度、标题候选、首封草稿和跟进节奏。
