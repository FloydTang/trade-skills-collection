# 工作间

这个目录是当前 `外贸skill` 分类下的长期记录层和内部方法层。

它对应的是 Obsidian `工具工作间/02_场景拆解/外贸业务主干Skill`，不是 Obsidian 顶层“工具工作间”本身。

这里的长期记录一旦稳定，应在 Obsidian `工具工作间/02_场景拆解/外贸业务主干Skill` 里有对应展现。展现形式可以是镜像、摘要、索引或说明，不要求复制执行层文件。

这里只保留会被反复复用、反复判断、反复协作的有效内容。

顶级原则固定为：

`实事求是、简洁高效`

## 只保留什么

- 已经看过并值得继续保留判断的开源项目
- 这些项目与当前外贸 Skill 路线的映射关系
- 是否进入 `skill需求池.md` 的明确建议
- 不对外公开交付的内部方法层和孵化方向

## 不保留什么

- 每天搜索过程的细节噪音
- 为了留痕而留痕的中间表
- 与后续判断无关的大段日报搬运

- `内部维护/外贸业务主干/`
- `内部维护/`
- `制作中/`

如某个方向已经进入持续推进、且后续会被课程、品牌、产品表达反复引用，可以补充少量“推进说明”类文档，但展示层默认收进 `内部维护/` 或对应 `制作中/`，不要继续在 Obsidian 根目录平铺。

- 只补长期会复用的人类阅读文档
- 不把执行过程噪音搬进来

## 维护规则

- `工具工作间与工具库到课程工作间联动说明_2026-05-20.md` 是课程工作间读取工具资产前的同步契约
- `外贸业务主干Skill云端同步清单.md` 是外贸业务主干 Skill 给课程工作间读取的资产入口
- `精选外挂开源Skill云端同步清单.md` 是外挂开源工具和 Skill 给课程工作间读取的资产入口
- `开源工具总表.md` 是外挂候选主表，镜像到 `内部维护/`
- `路线映射.md` 只负责回答“怎么用”，镜像到 `内部维护/`
- `skill需求池.md` 只接收已经形成明确方向判断的内容
- `首次安装与增强入口标准话术.md` 和 `公开分发与增强承接说明.md` 是公开仓库与飞书增强权益之间的稳定边界口径
- 如果一个信息未来不会被再次引用，就不要写进这里
- 如果一个记录未来会被课程、品牌、产品表达反复引用，就应同步到 Obsidian 对应文件夹可见

## 成品落库规则

一旦 Skill 达到可演示或可交付，并准备进入课程化同步：

1. 成品放入 `半斤九两工具库/外贸业务主干Skill`
2. 工具工作间只保留立项、验证和后续优化记录
3. 同步清单更新状态、工具库落点、课程同步建议和风险边界
4. 课程工作间读取工具库，改写成课程库正文、作战台同步稿和飞书知识库同步内容

作战台不直接读取工具工作间，也不把工具库当最终用户展示层。
