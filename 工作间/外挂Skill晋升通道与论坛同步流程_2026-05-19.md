# 外挂 Skill 晋升通道与论坛同步流程 2026-05-19

## 一句话

外挂 Skill 不从论坛直接进工具库，也不从 GitHub 列表直接进作战台。

稳定通路是：

```text
工具工作间候选
-> 本地 POC / 最小样例验证
-> 论坛试运行与反馈
-> 人工审核和脱敏
-> 半斤九两工具库落库
-> 作战台弹药库 / 论坛 Skill / 课程中心按权限同步
```

## 现有作战台通路

当前作战台已经有几条可以承接这套流程的能力：

- `#/forum`：年度会员论坛，支持看帖、提问、回答、Skill 分享、工具推荐和待审核发布。
- `scope=forum` 学习链接：年度会员可给智能体，让智能体读论坛、整理帖子和提交草稿。
- Agent API：智能体可读取论坛 feed，也可提交帖子 / 回答草稿；提交后进入主人待审核区，不自动公开。
- `forum_skill_requests`：用于记录用户对帖子或精选内容的“希望沉淀成 Skill”请求。
- `/api/library`：弹药库只展示 `libraryReady` 资产；当前门槛是已审核、来源存在、正文长度足够，且不处于 `needs_review`。
- `assetKind=skill`：只有绑定明确开源 Skill 骨架、安装入口或 `skill.md` 的资产，才在作战台里标为 Skill；否则只能叫描述词或工具参考。

## 晋升分层

| 层级 | 名称 | 存放位置 | 进入条件 | 出口 |
| --- | --- | --- | --- | --- |
| L0 | 发现候选 | `工作间/开源工具总表.md`、`优质外挂工具与Skill候选清单_2026-05-19.md` | 有明确来源和可能业务用途 | 进入 POC 清单或只保留参考 |
| L1 | POC 候选 | `外挂工具POC推进清单_2026-05-19.md` | 能对应外贸、内容、知识库、设计或工程维护场景 | 做最小样例 |
| L2 | 本地验证中 | `工作间/孵化中/` 或内部维护文档 | 能跑出可复查样例，有失败边界 | 进入论坛试运行或继续迭代 |
| L3 | 论坛试运行 | 作战台 `#/forum` 的 `Skill 分享` / `工具推荐` | 已脱敏，有用处、帮助、验证证据和安全边界 | 收集讨论、投票、Skill 请求 |
| L4 | 工具库预发布 | `半斤九两工具库/外贸skill` | 人工审核通过，有安装/使用/边界/验证记录 | 进入同步清单 |
| L5 | 作战台发布 | 作战台弹药库 / 论坛 Skill / 授权学习链接 | `approved`、有来源、可复制或可安装、权限正确 | 用户可见或按权益锁定 |
| L6 | 课程中心回流 | 课程正文、飞书知识库、课程中心 | 改变课程打法或新增稳定作业 | 更新课程内容 |

## 每日节奏

每日可以让 AI 工具自动做这些事：

1. 读取论坛 `hot / latest / Skill 分享 / 工具推荐 / 龙虾日记`。
2. 从每条帖子里抽取：名称、用处、给外贸企业的帮助、验证证据、风险边界。
3. 把明显不适合公开的内容打回：含客户隐私、API Key、报价细节、未脱敏成交数据。
4. 对值得推进的内容生成候选卡，但只进入工作间或论坛待审核区，不直接落工具库。
5. 给运营者输出每日摘要：新增候选、待验证、可回帖、可沉淀为 Skill。

每日更新的目标是“发现和整理”，不是“发布和落库”。

## 每周节奏

每周做一次人工晋升：

1. 从论坛 Skill 请求、POC 清单和候选清单里选 1-3 个最高价值方向。
2. 补齐本地最小样例、失败边界和来源证明。
3. 判断资产类型：
   - 有开源骨架、安装入口或 `skill.md`：可以标成 Skill。
   - 只有一段执行词或帖子摘要：只能标成描述词或工具参考。
4. 通过后落到 `半斤九两工具库/外贸skill`，并更新两份云端同步清单。
5. 如果要进作战台弹药库，再生成或更新 D1 migration / seed，保证 `content_review_status='approved'`、来源字段完整、正文足够长。
6. 如果影响课程打法，回流课程中心和飞书知识库。

## 工具库落库要求

每个外挂精选资产进入工具库前，至少要有：

- `README.md`：它是什么、解决什么业务问题、适合谁用。
- 来源与许可证：GitHub / 官方文档 / 已装本地 Skill 来源。
- 最小样例：输入、执行方式、输出结果、失败样例或误报说明。
- 安全边界：隐私、账号、API Key、数据出境、误判风险。
- 作战台呈现建议：成品、验证中、只参考；是否可复制、可收藏、可授权给智能体。
- 课程回流判断：是否需要更新课程正文、飞书知识库或论坛置顶帖。

没有这些材料，不进入工具库成品层，只能留在工作间或论坛试运行。

## 论坛与工具库边界

论坛负责讨论、试用、反馈、投票和沉淀需求。

工具库负责保存已经提纯、验证、可追溯、可被作战台读取的成品。

所以不能让论坛帖子自动写入工具库；论坛里再热的内容，也必须过一次本地验证和人工审核。反过来，工具库成品可以同步到论坛做“本周新增弹药”说明，帮助会员知道怎么用。

## 推荐的首批晋升方向

| 方向 | 当前状态 | 建议动作 |
| --- | --- | --- |
| `changedetection.io` / 竞品监控 | 已有最小样例和作战台价值 | 优先做 L3 论坛试运行，再判断是否 L4 落库 |
| `llm_wiki` / 本地企业知识库 | 候选价值高 | 先做本地 POC，不急着进论坛 |
| `AfterShip/email-verifier` + `mailchecker` | 与客户开发强相关 | 做邮箱质量最小样例，重点验证误判 |
| `sherlock` / `maigret` | 已作为社媒初筛候选 | 先验证误报，论坛只展示方法和边界 |
| `html-anything` / `wechat-publish-template` / `snapdom` | 内容输出链候选 | 可进入内容营销方向试运行 |
| `12-factor-agents` | 方法层价值明确 | 转成 Agent 上架检查 gate，不作为用户运行时 Skill |

## 一条硬规则

作战台读取工具库，但工具库只吃“通过验证的成品”。工作间和论坛可以每天热闹，工具库要慢一点、硬一点、干净一点。
