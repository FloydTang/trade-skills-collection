# 开始这里

这个出口只做一件事：

把工具工作间从“到处都是文档”收成清楚的两类入口。

## 云端和作战台只看两份

1. `外贸业务主干Skill云端同步清单.md`
   - 半斤九两定制的外贸业务主干 Skill
   - 包括成品、制作中、孵化中、竞品监控、market pulse、飞书资料承接
2. `精选外挂开源Skill云端同步清单.md`
   - 精选外挂开源 Skill / 工具
   - 包括设计、内容、知识库、验证、研发辅助和可挂靠到外贸业务的上游工具

这两份是给作战台、课程中心和云端同步看的默认入口。

## 目录流转规则

```text
工具工作间 = 制作中 / 孵化中 / 验证中 / 内部维护
半斤九两工具库 = 已成功 / 可演示 / 可交付 / 云端可同步
```

已经成功的 Skill 不在工具工作间继续作为默认入口展示。后续如果要优化，也优先在 `半斤九两工具库/外贸skill` 的成品层继续优化，再同步给作战台。

## 现在怎么找

- 要给作战台同步：只看两份云端同步清单。
- 要继续做外贸业务 Skill：看 `制作中/外贸业务主干/`。
- 要继续做外挂工具 POC：看 `内部维护/精选外挂开源/`。
- 要追溯为什么这么分：看 `内部维护/外贸业务主干/作战台与课程中心Skill同步方向_2026-05-19.md`。
- 要看最终成品：去 `半斤九两工具库/外贸skill`。

## 不在根目录平铺什么

- 每日日报
- 临时同步副本
- POC 过程文档
- 历史计划和验证台账
- 已经落库的成品 Skill 说明

`实事求是、简洁高效`
