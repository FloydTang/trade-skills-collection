# 开始这里

这个出口只做一件事：

把工具工作间从“到处都是文档”收成清楚的两类入口。

## 课程工作间先看这三份

1. `工具工作间与工具库到课程工作间联动说明_2026-05-20.md`
   - 说明工具工作间、工具库、课程工作间、课程库、作战台和飞书知识库的完整链路
   - 这是课程工作间读取工具资产前的同步契约
2. `外贸业务主干Skill云端同步清单.md`
   - 半斤九两定制的外贸业务主干 Skill
   - 包括成品、制作中、孵化中、竞品监控、market pulse、飞书资料承接
3. `精选外挂开源Skill云端同步清单.md`
   - 精选外挂开源 Skill / 工具
   - 包括设计、内容、知识库、验证、研发辅助和可挂靠到外贸业务的上游工具

这三份是给课程工作间读取和学习的默认入口。作战台不直接读取工具工作间，也不把工具库当最终展示层；对外展示应经过课程工作间整理，沉淀到课程库，再同步作战台和飞书知识库。

## 目录流转规则

```text
工具工作间 = 制作中 / 孵化中 / 验证中 / 内部维护
半斤九两工具库 = 已成功 / 可演示 / 可交付 / 可供课程工作间读取
课程工作间 = 课程化表达 / 作业设计 / 权益边界 / 作战台同步稿
半斤九两课程库 = 用户可学习、可交付、可同步飞书知识库的正式内容
```

已经成功的 Skill 不在工具工作间继续作为默认入口展示。后续如果要优化，也优先在 `半斤九两工具库/外贸业务主干Skill` 的成品层继续优化，再交给课程工作间判断是否更新课程库、作战台和飞书知识库。

## 现在怎么找

- 要给课程工作间同步：先看联动说明，再看两份同步清单。
- 要继续做外贸业务 Skill：看 `制作中/`。
- 要继续做外挂工具 POC：看 `内部维护/`。
- 要追溯为什么这么分：可看已归档的 `作战台与课程中心Skill同步方向_2026-05-19.md`，但当前口径以联动说明和两份同步清单为准。
- 要看最终成品：去 `半斤九两工具库/外贸业务主干Skill`。
