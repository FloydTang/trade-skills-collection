5. `Hermes Web UI 旁路控制台`

1. `Codex Subagents 使用模板`

## 当前工作包

| 工作包 | 当前动作 | 二阶段条件 |
| --- | --- | --- |
| `WP1 本地知识库 POC` | 准备公司资料、产品资料、历史开发信样例 | 公司画像、产品资料卡、来源映射能进入开发信 / 背调输入 |
| `WP2 Agent 上架检查 gate` | 用模板评估本地知识库导入、授权学习链接、开发信草稿 | 至少 2 个真实功能跑通并反向修 PRD |
| `WP3 HTML 输出链 POC` | 选公众号、小绿书、报告各一份样例 | HTML 可粘贴、卡片可出图、品牌视觉合格 |
| `WP4 已装 Codex Skill 规范化` | 判断 `feishu-wiki-sync` 是否转正 | 能主动触发并完成回读验收 |
| `WP5 Hermes Web UI 旁路` | WP1-WP3 后再做 | 不破坏 Hermes / OpenClaw 稳态 |
| `WP6 询盘承接方向` | 暂只观察 Chatwoot 等边界 | 有明确客户场景后再立项 |
| `WP7 Codex Subagents 模板` | 整理何时使用、怎么拆任务、怎么配置 custom agents | 能在代码评审、工具验证、课程资料整理三类任务上形成可复制 prompt |
| `WP8 Multica 面板参考` | 只读评估派工、进度、技能沉淀和 runtime 注册逻辑 | 不破坏 Hermes / OpenClaw / Codex 稳态，并能转成作战台功能草图 |
| `WP9 TikTok 视频节点流` | 从 Flowboard 拆出选题、脚本、素材、视频、复盘节点 | 能落到 `trade-social-account-scan`、`trade-video-topic-library`、`trade-video-script-pack` 三个小方向 |

## 下一步建议

下一步直接做 `WP1 本地知识库 POC`。
它最贴近本地作战台的核心命题：资料不乱、结果不丢、原文件不动。
