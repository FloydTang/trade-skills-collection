## 当前工作包

| 工作包 | 当前动作 | 二阶段条件 |
| --- | --- | --- |
| `WP1 本地知识库 POC` | 准备公司资料、产品资料、历史开发信样例 | 公司画像、产品资料卡、来源映射能进入开发信 / 背调输入 |

| `WP4 已装 Codex Skill 规范化` | 判断 `feishu-wiki-sync` 是否转正 | 能主动触发并完成回读验收 |
| `WP5 Hermes Web UI 旁路` | WP1-WP3 后再做 | 不破坏 Hermes / OpenClaw 稳态 |
| `WP6 询盘承接方向` | 暂只观察 Chatwoot 等边界 | 有明确客户场景后再立项 |

## 下一步建议

下一步直接做 `WP1 本地知识库 POC`。
它最贴近本地作战台的核心命题：资料不乱、结果不丢、原文件不动。
