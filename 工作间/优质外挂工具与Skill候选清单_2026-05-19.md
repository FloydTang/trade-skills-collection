# 优质外挂工具与 Skill 候选清单 2026-05-19

> Obsidian 展现层维护镜像：`工具工作间/02_场景拆解/外贸skill/内部维护/精选外挂开源/优质外挂工具与Skill候选清单_2026-05-19.md`

## 当前结论

- 不建议把 Hermes 改为九二Code / 本地作战台主底座；Hermes Web UI 只做 home-mac / 管理员控制台旁路 POC。
- `llm_wiki` 优先进入本地作战台企业知识库 POC。
- `html-anything` + `wechat-publish-template` 优先进入品牌发布链 / HTML 输出层 POC。
- `12-factor-agents` 转成作战台 Agent 功能上架前检查清单。
- `CLI-Anything` 只挑相关 harness 做方法层参考，不全量安装。
- `open-design` 作为 Codex 旁路设计实验室，不进入用户端 V1 运行时。
- `chatwoot` 保留为后续询盘承接 / 客服上界样本，不进当前作战台。
- UI 组件站只做组件灵感库，不能让作战台变成炫技页面。

## 当前 Codex 已装高价值 Skill

- `web-access`：联网核验、网页读取、CDP 浏览器操作；继续作为 Codex 真实网页核验底座。
- `defuddle`：网页正文清洗成 Markdown；可吸收到品牌搜索源 / 内容入库链。
- `obsidian-markdown / obsidian-cli / obsidian-bases / json-canvas`：Vault 和 Obsidian-compatible 知识库工作流基础能力。
- `frontend-design / design-taste-frontend / ui-animation`：产品 UI、作战台 demo、组件审美和微动效组合。
- `smart-explore / mem-search / knowledge-agent / timeline-report / mars-memory-engine-for-codex`：长期工程维护、记忆、知识沉淀和项目复盘组合。
- `92ppt`：半斤九两课程 deck 专用 Skill。
- `trade-customer-intel`：外贸客户背调核心 Skill，属于作战台主动开发链路核心节点。
- `trade-ai-talking-head-video`：品牌工作间视频链路外挂。
- `feishu-wiki-sync`：本地 Markdown / 索引同步飞书 wiki/doc 的私有 Skill，建议后续转正。
- `hyperframes / remotion / ffmpeg / snapdom`：视频、HTML 卡片、DOM 转图和批量视频的输出链组合。
- `systematic-debugging / verification-before-completion`：根因排查和完成前验证的 Codex 质检规范。
- `claude-skills`：把资料、规则和案例抽成可复用 Skill 的方法层工具。
- `aihot`：AI 资讯和市场脉搏方法参考。
- `vercel-deploy` + Vercel 插件 skills：产品部署、验证和上线治理。
