# Trade Customer Intel

中英双语的开源 Codex Skill，用公开网页线索为外贸销售和客户开发生成结构化客户情报报告。

> 唯一开发源是 [trade-skills-collection](https://github.com/FloydTang/trade-skills-collection)；[trade-customer-intel](https://github.com/FloydTang/trade-customer-intel) 是独立发行镜像。

它是整套主动开发链路里的核心判断层：搜索负责找到候选，整理负责标准化，背调负责看清“这个客户最近发生了什么、为什么值得跟、应该从哪里切入”，开发信再调用这些判断写草稿。

## 这个 Skill 解决什么问题

- 只有公司名、联系人、邮箱或官网
- 公开信息分散、真假难辨
- 开发前需要先做保守的公司级背调
- 开发信需要更清晰的近期动态、市场变化和销售切入点，而不是模板式泛写

## 职责边界

- 负责公开网页证据收集
- 负责实体匹配、风险判断和报告生成
- 负责公司级背调主线
- 负责提取近期客户信号：LinkedIn / 社媒动态、新闻、招聘、融资、扩产、新仓库、渠道变化
- 负责提取市场信号：合规变化、关税、贸易协定、认证要求、目标市场采购压力
- 负责把可引用信号整理给开发信 Skill
- 联系人和职位只作辅助匹配
- 不负责批量搜客户入口
- 不负责替代人工直接外发邮件

## 当前默认能力

- 公司级主体核验
- 官网、社媒、公开网页证据整理
- 双语结构化报告
- 保守的风险评级
- 近期客户信号和市场/合规信号
- `EV-*` 证据账本与 `CL-*` 主张账本，区分事实、推断和假设
- SIEGER v2 主体、证据、卖方能力、产品匹配和风险决策门
- 少于 3 个证据化维度时不计算综合分
- 销售角度默认为 `proposed`，不自动批准

## 当前不默认承诺

- 精准个人邮箱稳定补齐
- 完整人物档案稳定补齐
- 完全自动化个性化触达
- 弱证据下强行生成个性化事实
- 替开发信 Skill 编造“客户最近发生了什么”

## 最小输入输出

- 输入：公司名、联系人名、邮箱、官网、市场信息、可选产品/方案信息
- 输出：执行摘要、身份快照、公司画像、数字足迹、近期客户信号、市场/合规信号、销售切入角度、风险评级、证据清单、放行判断

## 企业表格与规则沉淀

- 这是客户背调能力，不是固定背调表模板。
- 企业已有表头和知识库归口优先沿用；没有可用表格时，再按产品、市场和背调流程新建够用表。
- 用户确认新的背调规则、风险分级、近期信号判断、市场信号来源、证据权重、行业习惯或表头映射后，先追问：`是否更新到对应 Skill 以便下次自动复用`，授权后再写入 Skill。

## 依赖提醒

- 只用公开网络信息
- `已安装` 不等于 `已可用`
- 搜索工具要区分 `已安装`、`已配置`、`已登录`、`已跑通`
- LinkedIn 类能力不是默认开箱即用
- 云端和本地环境可能不同

## Quick Start

```bash
python3 ./scripts/build_customer_intel_report.py \
  --input-json ./examples/sample-input.json \
  --markdown-out /tmp/customer-intel.md \
  --json-out /tmp/customer-intel.json
```
