# 验收与边界

## 当前结论

组合包按“可作为系统工作流管道运行”验收，不以固定 demo 能跑作为交付标准。

已验证的交付条件：

- 四个节点及组合包回归可重复执行
- 支持从客户搜索或客户背调开始
- 支持 `live_web`、`evidence`、`reviewed_report` 三种背调输入
- 运行状态、阶段、退出码、下一步和全部登记产物 SHA-256 写入 manifest
- 销售角度审批绑定 `run_id`、报告 SHA-256、角度、审核人和时间
- 审批写入中断可恢复；旧审批、被修改或缺失的输入输出会阻断续跑
- 多文件阶段提交失败时回滚，避免新旧产物混用
- 食品、消费品和工业场景文案隔离，内部角度指令不进入客户可见正文
- `follow_up` 必须提供真实前序沟通上下文

## 运行边界

- 证据不足时退出 `11`，不生成可发送开发信
- 未完成人工销售角度审批时退出 `10`
- 配置或审批契约错误退出 `2`，阶段执行或完整性校验失败退出 `3`
- 最终邮件始终为 `manual_review_only`
- 不自动发送邮件，不自动写 CRM、ERP 或飞书正式业务数据
- 固定样例只用于回归，不代表真实市场现状

## 仍需企业侧配置

- 授权卖方资料、产品范围、禁用表达和证据来源
- 真实 CRM / ERP / 邮箱草稿箱适配器
- 企业账号权限、审计和数据保留策略

这些是部署配置，不影响 Skill 本体和中立文件管道的可运行性。
